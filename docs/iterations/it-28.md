### Note tecniche
- Il middleware gestisce tre zone: `/login` (pubblica), `/dashboard/*` (solo Admin/Owner/Employer), `/employee/*` (solo Employee)
- Gli Employee loggati su `/login` vengono reindirizzati a `/employee` (non `/dashboard`)
- Gli Admin che tentano di accedere a `/employee/*` vengono reindirizzati a `/dashboard`
- Il CSS employee usa le classi del prototipo HTML `UI/Dipendenti/turniup.css` integrato in globals.css per evitare doppioni
- Endpoint API employee seguono pattern `/api/employee/*` (da implementare lato API)
