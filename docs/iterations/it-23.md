### Obiettivo
Creare il progetto Expo (React Native + TypeScript) in `src/Mobile/` come base per la migrazione del progetto MAUI a Expo. Design system identico alla cartella `UI/` (tokens, tema light/dark, tutti i componenti condivisi). Il progetto MAUI in `src/Turnify.Mobile/` rimane intatto.

### Piano
1. Generare app Expo SDK 56 con `create-expo-app` — include Expo Router v3, TypeScript, react-native-reanimated, gesture-handler
2. Installare dipendenze aggiuntive: expo-secure-store, expo-notifications, expo-application, react-native-svg, axios, @expo-google-fonts/plus-jakarta-sans
3. Configurare `app.json` (Turnify, scheme, splash verde, FCM)
4. Creare design tokens da `UI/tokens.jsx` → `constants/tokens.ts`
5. Creare ThemeContext + AuthContext con SecureStore
6. Creare 16 componenti UI in `components/ui/` da `UI/components.jsx`
7. Creare API base con Axios + interceptor JWT + refresh automatico
8. Definire types TypeScript (auth, shift, employee, vacation, common)
9. Root `_layout.tsx` con font loading + provider stack
10. Routing skeleton: (auth), (admin), (employee) con placeholder screens
